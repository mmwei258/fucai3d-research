策略回测实验室

选一种策略，在真实历史数据上做严格样本外检验：预测第 N 期时只用第 N 期之前的数据。 结果会与"纯随机"的理论基线并列展示。

对照实验：排除最近 N 期已开出的号码，有用吗？

选号器里有一个「排除已开出的号码」开关（30 / 50 / 100 / 150 / 200 期可选）。 这里用同一批 500 期样本外数据直接检验它： 对每一期，先按策略排序 000~999，再剔除最近 N 期开出过的号码，然后取 Top20。 如果窗口越大命中率不升反降，说明它只能"少买少亏"，不能提高中奖概率。
