# 福彩3D 数据工具箱（网页版）

单文件、离线可用的网页工具。构建产物在 [`../docs/index.html`](../docs/index.html)，
启用 GitHub Pages 后可直接访问。

## 功能

| 页面 | 内容 |
|---|---|
| 概览 | 数据快照、最近 10 期、结构分布（实际占比 vs 理论值） |
| 走势图 | 三位数字走势（带连线）+ 和值/跨度折线，30/50/100/200 期可调 |
| 遗漏统计 | 每位每数字的出现次数 / 频率 / 平均遗漏 / 最大遗漏 / 当前遗漏 |
| 频率分布 | 数字频率多窗口对比、和值/跨度/组态分布 |
| 选号器 | 直选复式 + 组选复式 + 筛选条件（和值 0~27 / 跨度 0~9 / 遗漏 0~9999 / 大小比 / 奇偶比 / 胆码），实时计算注数 / 金额 / 覆盖概率 / 期望回收。胆码规则可选「必须全含 / 至少含一个」：三位号码最多含 3 个不同数字，选到第 4 个时自动切到「至少含一个」并说明原因。筛选输入框只收整数：越界的值不参与筛选（标红并写明范围），离开输入框时收进最近的合法值。排除已开出号码的窗口可选 不排除 / 30 / 50 / 100 / 150 / 200 期 |
| 策略回测 | 5 种策略的严格样本外回测，与随机基线逐项对比；另有「排除窗口对照」一键实验（5 策略 × 6 个窗口，看清排除最近 N 期已开号码的真实代价） |

**定位**：只做历史数据的统计呈现，不做任何号码预测。措辞红线见下文。

## 重新构建

```bash
# 1) 从仓库数据生成前端数据集（读取 data/all/history_official_all_features.json）
python3 tool/extract_data.py

# 2) 合并 html + css + 数据 + js 为单文件
python3 tool/build.py
```

产物写到 `../outputs/福彩3D数据工具箱.html`，发布时复制为 `docs/index.html`。

> `tool/data.js` 由 `extract_data.py` 生成，**不纳入版本管理**。


## 设计约束（改动时请遵守）

1. **措辞红线**：全站禁用 `必中`、`准确率`、`专家推荐`、`稳赚`、`包中`、`中奖率`。
   `预测` 仅可出现在否定语境（如"不做任何号码预测"）或方法学描述中。
2. **不做联系方式**：页面不得出现微信号、手机号、二维码、"加群"等导流内容。
3. **单文件自包含**：不得引入任何外部 `http(s)` 资源，保证离线可用。
4. **口径可核查**：所有展示的数值都必须能由原始开奖数据复算，且说明计算方式。
5. **不做投注建议**：只呈现数据，不给"推荐号""看好谁"。

## 手机适配

- 所有表格包在 `.table-scroll` 内，窄屏下容器内横向滑动，不撑破页面
- 数字按钮一行 5 个，触控目标 ≥ 44px
- 布局在 860px 折为单列，760px 以下进一步收紧字号与内边距
